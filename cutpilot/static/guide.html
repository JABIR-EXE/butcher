CUTPILOT · LOCAL WEB APP

Quick setup guide.

Set up your product catalogue, map a sales export from your existing till, and review the business dashboard. This is local preview mode, not the hosted customer service.

1. Start CutPilot

On Windows, double-click run.bat. On macOS/Linux, open a terminal in the project folder and run:

python3 -m pip install -r requirements.txt
python3 app.py

Then open http://127.0.0.1:8765.

2. Import your product catalogue first

Open Import data. Download and fill one product template. One row represents one product/SKU. Include at least the product name; also provide SKU, stock unit, purchase cost, selling price and physical opening stock so stock value and gross-profit estimates are meaningful.

  • Product CSV example
  • Product Excel example
  • Product XML example

3. Import sales each day

Export item-level lines from your till/POS. One row is one product line sold, not one daily cash total. Required fields are sale date, quantity, and product name or SKU. Recommended fields are unit, unit price or line total, and receipt/sale ID.

  • Sales CSV example
  • Sales Excel example
  • Sales XML example

CSV, XLSX/XLSM and the supplied simple row-based XML are supported. The importer suggests column matches from header names. If a heading is wrong or not recognised, select the correct source column from the mapping dropdown, review the rows and errors, then confirm. This matching is rules-based, not an AI model. Complex POS-specific XML may need converting to the supplied structure.

Leave stock deduction unchecked for historical sales. Only deduct current sales if they have not already been reflected in inventory. Product imports do not change existing stock unless you explicitly enable the stocktake option.

4. Understand pricing and the customer model

Open Plans & pricing to see proposed Starter, Professional and Multi-location prices. These are founder pricing hypotheses only; checkout is not active. Hosted account pilot is available in SaaS mode: each owner can register and receive a separate business workspace. The standard local preview still has one shop. The supplied hosting template is not deployed, the current pilot uses per-business SQLite files on one persistent-disk instance, and billing is not active. Do not expose local preview to the public internet.

5. Test recommendations

Open Purchasing, recalculate the forecast, select suggested products, and create draft orders. In Purchase orders, approve and receive an order to add inventory. You can also record waste and ask the assistant questions.

6. Run tests

python -m unittest discover -s tests -v

Read docs/IMPORT_FILE_SPECIFICATION.md for the full column contract and docs/SELLING_CUTPILOT.md for a short owner pitch, proposed pricing and hosted-vs-local guidance. The included Plans & pricing page remains available in the sidebar.
